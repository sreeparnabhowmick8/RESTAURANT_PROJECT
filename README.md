# 🍽️ Restaurant Website

A modern and responsive Restaurant Website built using **HTML, CSS, and JavaScript**.  
This project provides an attractive user interface for customers to explore food menus, order food online, reserve tables, and view restaurant services.

---

## ✨ Features

- 🏠 Responsive Home Page
- 🍕 Multiple Food Menu Categories
- 🛒 Online Food Ordering System
- 📅 Table Reservation Booking
- 👨‍🍳 Chef Section
- ⭐ Customer Reviews & Ratings
- 🖼️ Food Image Gallery
- 🔐 User Sign In Page
- 📱 Mobile Friendly Design
- 🎞️ Animated Slideshow & Hover Effects
- 📞 Contact & Customer Service Section

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

---

## 🎯 Project Objective

The main objective of this project is to design a real-world restaurant website interface while improving frontend web development skills, UI design, responsiveness, and user interaction.
